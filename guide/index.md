# 开始阅读

当前文档站的默认语言是简体中文，当前默认展示的文档版本对应：

- Croparia IF `1.1.0a`
- Minecraft `1.21.1`

## 文档入口

- [文档架构](/guide/architecture)
- [多语言与多版本](/guide/i18n-and-versioning)
- [版本策略](/versions/)

## 约定

- 根路径 `/` 代表当前版本的中文文档。
- 英文文档位于 `/en/`。
- 历史版本预留在 `/versions/<version>/` 与 `/en/versions/<version>/`。
