# Overview: General

Croparia IF is a Minecraft Java Edition mod that adds many crops capable of producing a wide range of materials, including ores, mob drops, and other rare resources. The mod also provides substantial customization features to make life easier for modpack authors.

It originally began as a fix-and-customization-enhancement branch based on [Dalarion's Croparia 4.5 - 1.20.1](https://github.com/Dalarion/Croparia), but after multiple rounds of refactoring and expansion, its codebase, art, and overall implementation have been completely renewed.

## Version support

Supported loaders: Fabric, NeoForge (1.21+), and Forge (1.20-)

Supported Minecraft versions:

- Long-term support (`LTS`): **1.20.1**, **1.21.1**
- Short-term support (`STS`): **1.18.2**, **1.21**, **1.21.2**, **1.21.3**, **1.21.4**, **1.21.11**

That means:

- `1.19.x` and below remain available as historical releases, but no longer receive ongoing feature work.
- When a newer version stops receiving continued updates, it moves from active maintenance into `STS`.
