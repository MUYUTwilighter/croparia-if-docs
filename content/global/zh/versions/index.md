# 版本策略

当前站点的默认落地页始终指向当前维护版本。

## 当前版本

- Croparia IF `1.1.0a`
- Minecraft `1.21.1`
- 当前中文入口：[/](/)
- 当前英文入口：[/en/](/en/)

## 历史版本路径

- 中文：`/versions/<version>/`
- 英文：`/en/versions/<version>/`

## 文档复用策略

历史版本不会默认复制整套文档，而是按下面的方式组合：

1. 先读取共享基础内容
2. 再叠加目标版本自己的覆盖文件
3. 只有确实发生变化的页面才需要单独落盘
