# Players

This section is for people actively playing the mod. Its main goal is to answer “how do I start”, “how do I keep progressing”, and “where do I look when something goes wrong”.

## Recommended reading order

- [Getting Started](getting-started.md): the full early-game route from installation and mining Elematilius Ore to crafting Croparia and upgrading it.
- [Automation Ideas](automation.md): automation examples built around the Greenhouse, Infusor, Ritual Stand, and external logistics mods.
- [FAQ](faq.md): a concentrated list of answers for installation, compatibility, gameplay understanding, and troubleshooting.

## Before you start

- If you want to confirm which systems, blocks, and items the mod contains, start with [General](../general/index.md).
- If you mainly need customization, configuration, and data pack details, move to the [Modpack Authors docs](../modpack/index.md).
- If you need source-level architecture or API details, move to the [Developer docs](../developer/index.md).
