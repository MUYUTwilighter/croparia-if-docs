# 通用概览

这一分类记录 Croparia IF `1.1.0a` 中显式可见、适合所有读者先建立共识的信息。

## 这一类要写什么

- 模组的基础定位与当前版本范围。
- 玩家与创作者都能直接观察到的内容分类。
- 统一术语，例如 Croparia、元素、仪式、转化器、温室。
- 物品、方块、流体、特殊道具等可检索信息。

## 这一类不写什么

- 不展开具体游玩路线。
- 不解释数据格式、命令参数或源码结构。
- 不把玩法建议和设计建议混进清单页。

## 写作规划

### 第一阶段

- 建立稳定的名词定义。
- 整理主要内容分组，确保玩家页和开发者页引用时不会重复解释。

### 第二阶段

- 加入表格化清单。
- 为核心对象补充一句话用途说明。
- 视情况加入配图或图标。
