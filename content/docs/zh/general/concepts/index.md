# 术语与核心概念

本页用于统一 `1.1.0a` 文档中的基础名词，避免后续页面各写各的定义。

## 计划覆盖的术语

- `基础魔种`：作为分级核心物品的定位，以及它和作物扩展之间的关系。
- `作物` 与 `巨果`：两类可种植内容的区别，是否共享升级与产出逻辑。
- `Tier`：作物、Croparia、仪式台等内容里的等级概念。
- `元素`：`Fire`、`Water`、`Earth`、`Air` 与 `Elemental` 的关系。
- `Infuse / Soak / Ritual / Transmute`：几类核心处理过程分别在做什么。
- `温室`、`作物嬗变仪`、`元素石`：作为系统节点时的功能定位。

## 页面结构规划

1. 先给出一份短定义表。
2. 再用“概念关系”小节说明这些术语如何连成玩法和数据体系。
3. 最后列出常见混淆点，例如元素本体与元素流体、作物果实与材料产物。

## 写作边界

- 只说明概念，不写操作步骤。
- 不写 JSON 或代码示例。
- 如果某个概念只对开发者有意义，放到开发者页详细说明，这里只保留一句定义。
