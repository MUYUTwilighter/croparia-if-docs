# 作物

作物是 Croparia IF 玩法内容的核心，它以耕作为框架，实现各种资源物品的量产。

<a id='crop'></a>

## 果实作物

果实作物，与原版的单格普通作物类似，但主要用于生产物品材料。每一个果实作物都有对应的**作物种子**、**作物果实**与**作物方块**。

**作物果实**可以通过对着地面右键、合成以及[作物嬗变仪](../blocks-and-items/workstations.md#croparia:crop_transmuter)转变为物品材料。

<a id='melon'></a>

## 巨果作物

巨果作物，与原版的瓜果作物（南瓜、西瓜等）类似，主要用于生产方块材料。每一个巨果作物都有对应的**巨果种子**、**巨果**与**巨果藤**。

**巨果藤**可以通过骨粉催熟，对成熟的巨果藤使用骨粉可以促进结果。

**巨果**可以通过合成与[作物嬗变仪](../blocks-and-items/workstations.md#croparia:crop_transmuter)转变为方块材料。
