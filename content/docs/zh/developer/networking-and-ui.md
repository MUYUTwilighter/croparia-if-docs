# 网络与界面

当前源码中最明确的交互式界面集中在 Crop Transmuter，本页将以它为主线整理网络与 UI 协作关系。

## 计划覆盖内容

- 菜单注册与容器对象。
- 客户端界面与交互状态。
- 选择输出、红石模式等网络消息。
- 服务端同步与校验边界。

## 页面重点

- 明确哪些状态由服务端裁定。
- 说明客户端界面只是表达层还是也承担本地逻辑。
