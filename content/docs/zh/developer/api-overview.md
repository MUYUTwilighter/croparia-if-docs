# API 总览

本页的目标是筛出下游开发者最值得关注的公开入口，而不是把整个源码树都罗列一遍。

## 计划覆盖内容

- 推荐依赖的包与类。
- 可以读取或查询的注册表与数据对象。
- 可扩展或可复用的处理器、接口、工具类。
- 哪些内容属于内部实现，暂不建议直接耦合。

## 页面输出形式

- 以“用途 -> 入口”组织，而不是按文件名堆叠。
- 对每个入口补一句稳定性预期。
