# 开发者文档

这一分类面向会阅读源码、需要与 Croparia IF 协作或扩展其能力的下游开发者。

## 这一类要写什么

- 项目在 common 层的主要架构。
- 关键包结构与职责边界。
- 注册体系、数据模型、配方加载、网络与界面。
- 公开 API 与潜在扩展点。

## 写作边界

- 面向会看源码的读者。
- 但目标仍然是降低上手成本，而不是简单照抄包名和类名。
