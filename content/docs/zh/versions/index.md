# 版本策略

当前站点的默认落地页始终指向当前维护版本。

当前版本状态约定：

- `Current`：当前主维护版本
- `LTS`：长期支持版本
- `STS`：短期支持或已停止继续更新的历史版本

## 当前版本

- Croparia IF `1.1.0a`
- 兼容 Minecraft `1.21.1`
- 当前中文入口：[/](/)
- 当前英文入口：[/en/](/en/)

## 当前支持策略

- `1.20.1`、`1.21.1`：按长期支持版本维护
- `1.19.x` 及更低版本：后续不再继续更新，视为 `STS`
- 后续停止更新的版本，也会在文档与导航中标记为 `STS`

## 历史版本路径

- 中文：`/versions/<version>/`
- 英文：`/en/versions/<version>/`

## 标签分发策略

兼容多个版本的页面不需要手动复制到各版本目录，而是通过 `modVersions` 标签声明适用版本，由生成脚本自动输出。

文档版本默认以 Croparia IF 模组版本为主轴；只有在确实存在版本差异时，才额外标注具体的 Minecraft 版本行为。
