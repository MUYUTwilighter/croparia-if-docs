# 数据包与资源包

本页用于说明整合作者应如何把 Croparia IF 的自定义内容组织进包体资源。

## 计划覆盖内容

- 模组在数据与资源层面暴露了哪些入口。
- 内容文件应该如何组织。
- 与内置内容冲突时的覆盖策略与注意事项。
- 多语言、贴图、模型与数据定义之间的关系。

## 不在本页展开的内容

- 具体作物字段放到“自定义作物”。
- 具体配方结构放到“配方与结构”。
