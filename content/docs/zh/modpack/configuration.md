# 配置与整合建议

本页用于梳理会直接影响整合包体验的主要配置点，并给出写法与设计建议。

## 计划关注的主题

- 功能开关类配置。
- 自动重载与覆盖行为。
- 与水果使用、尝试次数或平衡性相关的选项。
- 何时应该调整默认值，何时应保留原样。

## 页面风格

- 优先解释“影响什么”，再给出配置名。
- 避免把配置表写成纯粹的键值转录。
