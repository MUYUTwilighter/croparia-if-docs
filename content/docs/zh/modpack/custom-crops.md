# 自定义作物

这一页会成为整合包作者文档中的重点页，围绕作物定义与验证流程展开。

## 计划覆盖字段与概念

- 作物命名与命名空间限制。
- 材料关联。
- tier、type、color 等核心字段。
- 翻译、种子、果实、方块表现之间的关系。

## 计划补充的工作流

1. 设计目标作物。
2. 编写或生成定义。
3. 用查询、导出或游戏内表现验证结果。
4. 处理命名冲突与替换策略。

## 页面重点

- 强调稳定的命名规范。
- 用示例解释常见错误，而不是只列字段表。
