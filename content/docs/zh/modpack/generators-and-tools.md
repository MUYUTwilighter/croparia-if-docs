# 生成器与工具

这一页聚焦帮助整合包作者提效的工具链入口。

## 计划覆盖对象

- `Recipe Wizard`
- generator 相关命令
- dump 与 query 能力
- 内置生成器的导出与清理流程

## 计划说明的重点

- 这些工具分别解决什么问题。
- 它们的输出结果应该如何被二次整理进整合包。
- 什么时候适合用工具生成，什么时候适合手写。
