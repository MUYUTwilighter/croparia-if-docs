# 1.1.0a 归档说明

这个归档只覆盖 `1.1.0a` 与当前主线相比确实存在行为差异的页面。

当前已经提供的专有页面集中在开发者文档中，主要涉及：

- `Repo API`
- `作物嬗变仪` 的自动化输入输出约束

如果某个页面在 `1.1.0a` 下没有单独归档，通常表示它和当前主线文档相比没有需要单独区分的行为差异。
