# 版本策略

当前主线文档对应的模组版本是 `1.1.1a`。

历史版本会在 `/versions/<version>/` 下提供归档页面，但只有在内容、行为或信息架构与当前主线不同的时候，才会建立专有覆盖页。

## 当前状态

- `1.1.1a`
  - 当前版本
  - 主线文档直接维护在 `/`
- `1.1.0a`
  - `STS`
  - 仅为与 `Repo` 锁定过滤相关的开发者页面提供专有归档
