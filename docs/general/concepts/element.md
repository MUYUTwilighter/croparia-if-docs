# 元素

元素是 Croparia IF 背景设定的一部分，本身的游玩内容不多，主要作为合成与升级[魔种](../blocks-and-items/croparia.md#croparia:croparia)的材料。

<a id="gems"></a>

宝石可以用于合成对应的[元素药水](#potion)。

### 合成/来源

除元素宝石是通过[元素矿石](../blocks-and-items/others.md#elematilius_ore)挖掘而得外，其他宝石需要通过[仪式台](../blocks-and-items/workstations.md#croparia:ritual_stand)合成获取。

元素药水可以给[注魔台](../blocks-and-items/workstations.md#croparia:infusor)进行元素灌注。它可以在工作台中用 1 个玻璃瓶与
1 宝石合成。

元素流体主要用于模组兼容；若你只是想了解常规玩法，通常更需要关注[元素药水](#potion)与[元素石](../blocks-and-items/workstations.md#croparia:elemental_stone)。元素流体桶可以在工作台中用 1 个铁桶与 4 个宝石合成。
